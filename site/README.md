# OmniCore Site

Public portfolio portal for the OmniCore project. Hosted on GitHub Pages. This is the entry point for recruiters, engineers, and technical leaders reviewing the work.

The site is a React + TypeScript app built with Vite. It lives in `site/` because it represents the whole OmniCore project, not a business client or internal web app.

## Experience

- **Profiles:** Recruiter, Dev/Senior, CTO/CEO (soft toggle, non-blocking).
- **Languages:** ES / EN.
- **Tone:** close, technical, simple. Decisions and learnings should be visible to every profile.
- **Visual style:** editorial portfolio case study (`NR/OmniCore`), using the warm light NR/ palette, not a generic SaaS landing.

**Thesis (ES):** Construí OmniCore para mostrar cómo pienso cuando el software tiene que crecer.

## Local Development

Install dependencies:

```bash
npm install
```

Start the Vite dev server:

```bash
npm run dev
```

Run lint:

```bash
npm run lint
```

Build the static site:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## GitHub Pages

The site is deployed from the static build output generated by Vite:

```text
site/dist
```

`vite.config.ts` uses:

```ts
base: '/OmniCore/'
```

That base path is required because this is a GitHub Pages project site served under the repository path:

```text
https://nicolarebola.github.io/OmniCore/
```

Deploys are handled by `.github/workflows/site-pages.yml` when changes are pushed to `main` under `site/**` or the workflow file itself.
